# Ozon Funnel Auto

Отдельная автоматизация для дневной воронки Ozon. Проект не связан с `celicom-auto` и не изменяет его.

## Что делает

1. Открывает **Ozon Seller → Аналитика → Моя аналитика**.
2. Выбирает период **Год**.
3. Применяет сохранённый набор **«Демиткина - воронка»**.
4. Выбирает группировку **по дням** и формирует `Отчёт по дням`.
5. Ждёт готовности файла в менеджере загрузок и скачивает XLSX.
6. Проверяет наличие метрики **«Уникальные посетители с просмотром карточки товара»**.
7. Обновляет только `G:Y` листа **«Реклама руками (воронка)»** в книге `Ozon_Bags&Clo_2026`.

Столбцы `A:F` и формулы на листе `ДБ Артикул New` скрипт не меняет. Если обязательных столбцов нет или отчёт пустой, Google-таблица не обновляется. Если запись оборвётся, скрипт пытается восстановить предыдущие значения `G:Y`.

## Секреты GitHub Actions

- `OZON_STORAGE_STATE_B64` — сессия Ozon Seller;
- `GOOGLE_SERVICE_ACCOUNT_JSON` — JSON сервисного аккаунта Google.

## Запуск

- вручную: **Actions → Ozon funnel daily → Run workflow**;
- автоматически: ежедневно в `07:30 МСК`.
